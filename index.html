⚙️ Teacher Setup

Dán URL Web App của Apps Script để kết nối AEEF với Google Sheet riêng của giáo viên. URL chỉ được lưu trên thiết bị này và không làm thay đổi người dùng khác.

Chỉ dùng URL triển khai kết thúc bằng /exec. Không dùng URL thử nghiệm /dev.

Quy trình: Copy Google Sheet → Extensions → Apps Script → Deploy as Web App → Copy URL /exec → Dán vào đây.
